# Todo App

Une application simple de gestion des tâches (todo) construite avec HTML, CSS et JavaScript.

## Fonctionnalités

- Ajouter de nouvelles tâches
- Marquer les tâches comme terminées
- Éditer les tâches en ligne
- Supprimer les tâches
- Filtrer les tâches : Toutes, Actives, Terminées
- Persistance des données dans le localStorage

## Utilisation

Ouvrez simplement le fichier `index.html` dans votre navigateur web pour utiliser l'application.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript (ES6+)

## Structure du projet

- `index.html` : Structure principale de l'application
- `styles.css` : Styles CSS pour l'interface
- `script.js` : Logique JavaScript pour la fonctionnalité

## Installation

Aucune installation n'est requise. Téléchargez ou clonez le dépôt et ouvrez `index.html` dans un navigateur moderne.
